# Go Trainer — путь с нуля

Тренажёр по Go для тех, кто раньше не писал на этом языке. 13 разделов,
71 задание: от `package main` до горутин, reflection и дженериков.

Каждое задание — отдельная папка с условием, теорией, тестами, заготовкой,
эталонным решением и решением с комментариями. Всё проверяется побайтовым
сравнением вывода, поэтому «почти правильно» не засчитывается.

---

## Быстрый старт

### 1. Ничего устанавливать не нужно

Портативный Go уже лежит в `tools/go`. Скрипты сами находят его и выставляют
`GOROOT`, `PATH`, `GOCACHE`.

Из корня `go_trainer` в Git Bash:

```bash
source scripts/lib.sh
cd tasks/01_basics/01_hello_world
go run main.go
```

В PowerShell:

```powershell
$env:GOROOT = "$PWD\tools\go"
$env:PATH = "$env:GOROOT\bin;$env:PATH"
$env:GO111MODULE = "off"
cd tasks\01_basics\01_hello_world
go run main.go
```

Ожидаемый вывод:

```text
Hello, Go!
```

### 2. Как проходить задание

1. Открой `README.md` — там условие и примеры.
2. Прочитай `theory.md` — короткий разбор темы.
3. Открой `main.go`, найди `// TODO` и допиши программу.
4. Запусти `go run main.go` и сравни с примерами.
5. Проверь себя автотестом:

```bash
bash run_tests1_1.sh
```

6. Если не получается — посмотри `solution.go` и `solution_commented.go`.

### 3. Проверка всех заданий

```bash
cd go_trainer
bash scripts/run_all.sh --solution
bash scripts/run_all.sh --commented
```

Обе команды должны напечатать:

```text
Пройдено: 71/71
```

### Что внутри по разделам

**01. Основы.** `package main`, `func main`, импорты, переменные, `fmt`,
исправление намеренно сломанного кода.

**02. Ввод и вывод.** `fmt.Scan`, указатели, чтение строки целиком,
`Printf`, форматирование чисел.

**03. Выражения.** Целочисленное деление, остаток, `math.Pi`, приведение
типов, логические выражения.

**04. Циклы.** Единственный цикл `for`, `range`, `break`/`continue`,
накопление, FizzBuzz, XOR.

**05. Срезы.** `make`, `append`, `len`/`cap`, разворот, дубликаты,
`sort.Ints`, циклический сдвиг.

**06. Строки.** Байты и руны, `utf8.RuneCountInString`, регистр,
`strings.Fields`, разворот, палиндром, шифр Цезаря.

**07. Структуры.** Поля, методы, получатель-значение и указатель,
конструктор `NewXxx`, `String()`, встраивание, интерфейсы.

**08. Map.** Подсчёт частот, comma-ok, множество на `map[T]bool`,
группировка, инверсия, сортировка ключей.

**09. Ошибки.** `error`, `errors.New`, `strconv.Atoi`, своя ошибка,
`errors.As`, `defer`, `panic`/`recover`.

**10. Файлы.** `os.ReadFile`, `os.WriteFile`, копирование, разбор чисел,
подсчёт слов, статистика файла.

**11. Горутины.** `go`, каналы, буферизация, `sync.Mutex`,
`sync.WaitGroup`, конвейер, пул воркеров.

**12. Bootcamp.** Простые числа, автомат с монетами, статистика,
гистограмма, сдвиг массива, матрица.

**13. Advanced.** Reflection: поля и вызов методов, type switch,
обобщённая функция `Max`.

## HTML-инструменты

### trainer.html

Просмотрщик заданий. Открой файл в браузере, нажми «Выбрать папку проекта»
и укажи папку `tasks`. Слева появится дерево разделов и заданий.

Что можно смотреть:

- условие (`README.md`);
- теорию;
- тесты;
- заготовку `main.go`;
- решение и решение с комментариями.

Настройки темы и размера шрифта сохраняются в `localStorage`.

### trainer_theory_tests.html

72 вопроса по 12 темам. Можно выбрать тему или собрать случайный набор.
После каждого ответа показывается разбор. Отдельный блок — reflection
и дженерики (раздел 13).

## Как проверяются задания

Автотест собирает файл и сравнивает **точные байты** вывода:

```bash
SOURCE_FILE=solution.go bash run_tests5_1.sh
```

- `run_case "вход" $'ожидание\n'` — вход через `printf`, ожидание в
  ANSI-C кавычках;
- `run_case_noeol` — без завершающего `\n`;
- `run_case_devnull` — пустой stdin;
- `run_case_args` — аргументы командной строки.

Файловые задания создают временные файлы в папке задания и удаляют их
через `trap`.

## Частые проблемы

**`go: command not found`.** Вы не выполнили `source scripts/lib.sh` или
не добавили `tools/go/bin` в `PATH`. Из корня тренажёра:

```bash
source scripts/lib.sh
```

Если папки `tools/go` нет (например, после клонирования репозитория, где
`tools/` исключён из git), установи Go 1.21+ или распакуй портативную
сборку в `tools/go`. Скрипты найдут её автоматически.

**`go.mod file not found`.** Скрипты выставляют `GO111MODULE=off`, потому
что каждое задание — один файл без модуля. При ручном запуске сделайте то
же самое.

**Вывод отличается пробелом или переводом строки.** Тесты побайтовые.
Проверьте, нужен ли `\n` в конце: `Println` добавляет его, `Print` — нет.

**Кириллица в выводе.** В заданиях вывод намеренно ASCII. Русские
комментарии в коде допустимы, но строки для тестов — только латиница.

**Файловое задание не находит файл.** Относительный путь считается от
текущего каталога. Запускайте тест из папки задания.

**Хочу пересобрать задания из спецификаций.** Из корня:

```bash
node build.js
```

Спецификации лежат в `specs/`. Это внутренний инструмент, для прохождения
заданий он не нужен.
