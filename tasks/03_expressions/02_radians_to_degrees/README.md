## GO_03_02. Радианы в градусы

### Задание
| GO_03_02 ||
| ------ | ------- |
| **Темы:** | `float64`, `math.Pi`, преобразование единиц |
| **Файл решения:** | main.go |
| **Входные данные:** | Угол в радианах |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай угол в радианах и переведи его в градусы:

~~~text
Degrees: 180.00
~~~

Формула: `градусы = радианы · 180 / π`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3.141592653589793 | Degrees: 180.00 |
| 1.5707963267948966 | Degrees: 90.00 |
| 0 | Degrees: 0.00 |
