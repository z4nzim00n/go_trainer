## GO_03_05. Логическое выражение

### Задание
| GO_03_05 ||
| ------ | ------- |
| **Темы:** | `%`, `||`, `bool` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи `true`, если число делится на 3 **или** заканчивается на 7.
Иначе выведи `false`.

Примеры: `9` → `true`, `17` → `true`, `10` → `false`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 9 | true |
| 17 | true |
| 10 | false |
