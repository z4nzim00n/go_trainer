## GO_03_03. Перестановка крайних цифр

### Задание
| GO_03_03 ||
| ------ | ------- |
| **Темы:** | `%`, `/`, цикл для поиска разряда |
| **Файл решения:** | main.go |
| **Входные данные:** | Целое число, не меньшее 10 |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Поменяй местами первую и последнюю цифры числа и выведи результат.

Пример: `1234` → `4231`.

Если после перестановки в начале оказывается ноль, он не печатается:
`10` → `1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1234 | 4231 |
| 12345 | 52341 |
| 10 | 1 |

### Как проверить

```bash
bash run_tests3_3.sh
```
