## GO_03_01. Площадь круга

### Задание
| GO_03_01 ||
| ------ | ------- |
| **Темы:** | `float64`, `math.Pi`, `fmt.Printf` |
| **Файл решения:** | main.go |
| **Входные данные:** | Радиус круга (вещественное число) |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай радиус круга и выведи площадь с двумя знаками после точки:

~~~text
Area: 3.14
~~~

Формула: `π · r²`. Используй `math.Pi`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 1 | Area: 3.14 |
| 2 | Area: 12.57 |
| 0 | Area: 0.00 |
