## GO_03_04. Ловушка целочисленного деления

### Задание
| GO_03_04 ||
| ------ | ------- |
| **Темы:** | целочисленное деление, приведение типов, `float64` |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два целых числа `a` и `b` и выведи их среднее арифметическое с двумя
знаками после точки.

~~~text
Avg: 3.50
~~~

Обрати внимание: `(a + b) / 2` при целых `a` и `b` даст целое число и потеряет
дробную часть.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 4 | Avg: 3.50 |
| 1 2 | Avg: 1.50 |
| -3 4 | Avg: 0.50 |

### Как проверить

```bash
bash run_tests3_4.sh
```
