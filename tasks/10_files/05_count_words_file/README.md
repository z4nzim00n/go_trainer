## GO_10_05. Слова в файле

### Задание
| GO_10_05 ||
| ------ | ------- |
| **Темы:** | файлы, `strings.Fields`, `len` |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Прочитай файл и посчитай количество слов в нём. Слова разделены пробелами,
табами и переводами строк. Выведи `Words: ...`.

~~~text
Words: 3
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| text.txt (`one two\nthree\n`) | Words: 3 |
| empty.txt | Words: 0 |

### Как проверить

```bash
bash run_tests10_5.sh
```
