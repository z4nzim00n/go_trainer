## GO_10_04. Сумма чисел из файла

### Задание
| GO_10_04 ||
| ------ | ------- |
| **Темы:** | файлы, `strings.Fields`, `strconv.Atoi` |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя файла с числами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Прочитай файл, в котором числа разделены пробелами и переводами строк.
Выведи их сумму: `Sum: ...`. Пустой файл даёт `Sum: 0`.

~~~text
Sum: 6
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| numbers.txt (`1 2 3\n`) | Sum: 6 |
| empty.txt | Sum: 0 |

### Как проверить

```bash
bash run_tests10_4.sh
```
