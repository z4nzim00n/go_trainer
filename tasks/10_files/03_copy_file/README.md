## GO_10_03. Копирование файла

### Задание
| GO_10_03 ||
| ------ | ------- |
| **Темы:** | чтение и запись, `os.ReadFile`, `os.WriteFile` |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя исходного файла и имя копии |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два имени файла. Скопируй содержимое первого во второй и выведи
`Copied: <содержимое без последнего перевода строки>`.
Если исходный файл не читается — выведи `Error: cannot read source`.

~~~text
Copied: hello
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| f1.txt f2.txt (в f1: `hello`) | Copied: hello |
| missing.txt f2.txt | Error: cannot read source |

### Как проверить

```bash
bash run_tests10_3.sh
```
