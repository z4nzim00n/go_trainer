## GO_10_01. Чтение файла

### Задание
| GO_10_01 ||
| ------ | ------- |
| **Темы:** | `os.ReadFile`, обработка ошибки |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай имя файла, прочитай его через `os.ReadFile` и выведи содержимое
без изменений. Если файла нет — выведи `Error: cannot read file`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| data.txt (содержит `hello`) | hello |
| missing.txt | Error: cannot read file |

### Как проверить

```bash
bash run_tests10_1.sh
```
