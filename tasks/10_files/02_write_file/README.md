## GO_10_02. Запись файла

### Задание
| GO_10_02 ||
| ------ | ------- |
| **Темы:** | `os.WriteFile`, права доступа, чтение после записи |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя файла и строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай имя файла и слово. Запиши слово в файл с переводом строки.
Затем прочитай файл обратно и выведи `Saved: <слово>`.

~~~text
Saved: hello
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| out.txt hello | Saved: hello |
