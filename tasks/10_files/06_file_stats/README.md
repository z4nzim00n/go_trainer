## GO_10_06. Статистика файла

### Задание
| GO_10_06 ||
| ------ | ------- |
| **Темы:** | файлы, подсчёт строк и байтов |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя файла |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Прочитай файл и выведи две строки: количество строк и количество байтов.

~~~text
Lines: 2
Bytes: 4
~~~

Файл `a\nb\n` содержит две строки и четыре байта. Пустой файл даёт нули.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| f.txt (`a\nb\n`) | Lines: 2<br>Bytes: 4 |
| empty.txt | Lines: 0<br>Bytes: 0 |

### Как проверить

```bash
bash run_tests10_6.sh
```
