## GO_06_01. Длина строки

### Задание
| GO_06_01 ||
| ------ | ------- |
| **Темы:** | `bufio.Scanner`, `utf8.RuneCountInString`, байты и руны |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку и выведи количество символов в ней.

Для строки `Hello` ответ `5`, для пустой строки — `0`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Hello | 5 |
| *(пустая строка)* | 0 |
| golang | 6 |
