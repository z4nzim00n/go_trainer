## GO_06_03. Верхний и нижний регистр

### Задание
| GO_06_03 ||
| ------ | ------- |
| **Темы:** | `strings.ToUpper`, `strings.ToLower`, две строки |
| **Файл решения:** | main.go |
| **Входные данные:** | Две строки |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай две строки. Первую выведи в верхнем регистре, вторую — в нижнем.

~~~text
HELLO
world
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| hello<br>WORLD | HELLO<br>world |
| Go<br>Lang | GO<br>lang |
