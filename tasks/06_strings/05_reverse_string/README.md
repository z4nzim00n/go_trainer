## GO_06_05. Разворот строки

### Задание
| GO_06_05 ||
| ------ | ------- |
| **Темы:** | руны, срезы, `strings.Builder` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку и выведи её в обратном порядке.

Разворачивай именно **символы**, а не байты.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| hello | olleh |
| Go | oG |
| abc def | fed cba |
