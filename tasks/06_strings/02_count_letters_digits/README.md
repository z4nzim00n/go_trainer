## GO_06_02. Буквы и цифры

### Задание
| GO_06_02 ||
| ------ | ------- |
| **Темы:** | `for range`, `unicode.IsLetter`, `unicode.IsDigit` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай количество букв и цифр в строке и выведи два числа через пробел:

~~~text
letters digits
~~~

Остальные символы (пробелы, знаки препинания) не учитываются.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Hello123 | 5 3 |
| abc | 3 0 |
| a1b2c3 | 3 3 |

bash run_tests6_2.sh
