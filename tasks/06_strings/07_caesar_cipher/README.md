## GO_06_07. Шифр Цезаря

### Задание
| GO_06_07 ||
| ------ | ------- |
| **Темы:** | руны, арифметика символов, `bufio.Scanner` |
| **Файл решения:** | main.go |
| **Входные данные:** | Сдвиг K и строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай сдвиг `K` и строку. Зашифруй строку шифром Цезаря: каждая латинская
буква сдвигается на `K` позиций по кругу, регистр сохраняется. Остальные
символы не меняются.

~~~text
3
Hello, World!
~~~

→

~~~text
Khoor, Zruog!
~~~

Сдвиг может быть отрицательным или больше 26.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>Hello, World! | Khoor, Zruog! |
| 1<br>abcXYZ | bcdYZA |
| 0<br>No change | No change |
