## GO_06_06. Палиндром

### Задание
| GO_06_06 ||
| ------ | ------- |
| **Темы:** | `unicode`, нормализация строки |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Определи, является ли строка палиндромом. Учитывай только буквы и цифры,
игнорируя регистр, пробелы и знаки препинания.

Выведи `true` или `false`.

Пример: `A man, a plan, a canal: Panama` → `true`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| A man, a plan, a canal: Panama | true |
| hello | false |
| 12321 | true |
