## GO_02_04. Форматированный вывод

### Задание
| GO_02_04 ||
| ------ | ------- |
| **Темы:** | `fmt.Scan`, `float64`, `fmt.Printf` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно вещественное число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай вещественное число и выведи его с двумя знаками после точки:

~~~text
Value: 3.14
~~~

Используй `fmt.Printf` с глаголом `%.2f`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3.14159 | Value: 3.14 |
| 2 | Value: 2.00 |
| -0.5 | Value: -0.50 |
