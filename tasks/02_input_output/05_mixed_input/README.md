## GO_02_05. Число и строка

### Задание
| GO_02_05 ||
| ------ | ------- |
| **Темы:** | `fmt.Scan`, разные типы в одном вводе |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя и возраст через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай имя (одно слово) и возраст, затем выведи:

~~~text
Hello, <имя>! You are <возраст>.
~~~

Например, для `Alice 30` результат:

~~~text
Hello, Alice! You are 30.
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Alice 30 | Hello, Alice! You are 30. |
| Bob 7 | Hello, Bob! You are 7. |
| Gopher 1 | Hello, Gopher! You are 1. |
