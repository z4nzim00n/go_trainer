## GO_02_03. Чтение строки целиком

### Задание
| GO_02_03 ||
| ------ | ------- |
| **Темы:** | `bufio.Scanner`, `os.Stdin`, `Scan` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка (может содержать пробелы) |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку целиком, включая пробелы, и выведи её в формате:

~~~text
Line: <строка>
~~~

Для пустой строки вывод: `Line: ` (с пробелом после двоеточия, без текста).

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| hello world | Line: hello world |
| Go is fun | Line: Go is fun |
| *(пустая строка)* | Line: |

bash run_tests2_3.sh
