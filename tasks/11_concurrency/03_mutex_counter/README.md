## GO_11_03. Счётчик с Mutex

### Задание
| GO_11_03 ||
| ------ | ------- |
| **Темы:** | `sync.Mutex`, `sync.WaitGroup`, гонки данных |
| **Файл решения:** | main.go |
| **Входные данные:** | Число горутин N |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Запусти `N` горутин. Каждая увеличивает общий счётчик 1000 раз.
Защити счётчик через `sync.Mutex` и дождись всех через `sync.WaitGroup`.
Выведи итог:

~~~text
Counter: 4000
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 4 | Counter: 4000 |
| 1 | Counter: 1000 |
| 0 | Counter: 0 |

### Как проверить

```bash
bash run_tests11_3.sh
```
