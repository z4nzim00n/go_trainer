## GO_11_05. Пул воркеров

### Задание
| GO_11_05 ||
| ------ | ------- |
| **Темы:** | пул горутин, `WaitGroup`, `close` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Создай 3 воркера и отправь им числа от `1` до `N`. Каждый воркер
возводит число в квадрат и возвращает результат. Суммируй результаты
и выведи `Total: ...`.

~~~text
Total: 55
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5 | Total: 55 |
| 3 | Total: 14 |
| 0 | Total: 0 |

### Как проверить

```bash
bash run_tests11_5.sh
```
