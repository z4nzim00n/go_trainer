## GO_11_01. Первая горутина

### Задание
| GO_11_01 ||
| ------ | ------- |
| **Темы:** | `go`, каналы, синхронизация |
| **Файл решения:** | main.go |
| **Входные данные:** | Ввод не нужен |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Запусти горутину, которая печатает `worker`. Главная функция печатает `main`,
дожидается горутины через канал и печатает `finished`.

~~~text
main
worker
finished
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| *(нет)* | main<br>worker<br>finished |

```bash
bash run_tests11_1.sh
```
