## GO_11_02. Две горутины

### Задание
| GO_11_02 ||
| ------ | ------- |
| **Темы:** | каналы, буферизация, суммирование |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа A и B |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Запусти две горутины: первая удваивает `A`, вторая удваивает `B`.
Результаты приходят через канал. Выведи сумму:

~~~text
Sum: 14
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 4 | Sum: 14 |
| 0 5 | Sum: 10 |

### Как проверить

```bash
bash run_tests11_2.sh
```
