## GO_11_04. Конвейер каналов

### Задание
| GO_11_04 ||
| ------ | ------- |
| **Темы:** | конвейер, `range` по каналу, `close` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Построй конвейер из двух стадий:
1. генератор отправляет числа в канал;
2. вторая стадия возводит каждое число в квадрат.

Главная функция суммирует квадраты и выводит `Sum: ...`.

~~~text
Sum: 14
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>1 2 3 | Sum: 14 |
| 2<br>2 4 | Sum: 20 |
| 0 | Sum: 0 |

### Как проверить

```bash
bash run_tests11_4.sh
```
