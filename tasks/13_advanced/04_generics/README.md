## GO_13_04. Обобщённый Max

### Задание
| GO_13_04 ||
| ------ | ------- |
| **Темы:** | дженерики, type parameters, `|` |
| **Файл решения:** | main.go |
| **Входные данные:** | Два числа |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Напиши обобщённую функцию `Max[T int | float64](a, b T) T`, возвращающую
большее значение. Считай два дробных числа и выведи максимум:

~~~text
Max: 7.50
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2.5 7.5 | Max: 7.50 |
| -1 -2 | Max: -1.00 |

### Как проверить

```bash
bash run_tests13_4.sh
```
