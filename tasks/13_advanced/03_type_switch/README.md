## GO_13_03. Type switch

### Задание
| GO_13_03 ||
| ------ | ------- |
| **Темы:** | `interface{}`, `type switch`, `strconv` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно слово |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай слово и определи его тип: целое число, дробное число или строка.
Выведи одно из:

~~~text
int: 42
float: 3.50
string: hello
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 42 | int: 42 |
| 3.5 | float: 3.50 |
| hello | string: hello |
