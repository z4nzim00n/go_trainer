## GO_13_02. Вызов метода через reflection

### Задание
| GO_13_02 ||
| ------ | ------- |
| **Темы:** | `reflect.Value`, `MethodByName`, `Call` |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши структуру `Calculator` с методом `Add(a, b int) int`.
Вызови метод через reflection и выведи результат:

~~~text
Result: 5
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 3 | Result: 5 |
| -1 1 | Result: 0 |
