## GO_13_01. Поля через reflection

### Задание
| GO_13_01 ||
| ------ | ------- |
| **Темы:** | `reflect`, `NumField`, `Type` |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя и возраст |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши структуру `Person` с полями `Name string` и `Age int`.
Считай значения и выведи все поля через reflection в формате
`Имя=значение`, разделяя пробелом:

~~~text
Name=Alice Age=30
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Alice 30 | Name=Alice Age=30 |
| Bob 0 | Name=Bob Age=0 |

### Как проверить

```bash
bash run_tests13_1.sh
```
