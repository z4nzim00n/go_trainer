## GO_12_04. Гистограмма

### Задание
| GO_12_04 ||
| ------ | ------- |
| **Темы:** | `map`, `strings.Repeat`, диапазон значений |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N чисел от 1 до 9 |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Построй горизонтальную гистограмму: для каждого встреченного значения
выведи `значение: ***`, где количество звёздочек равно частоте. Значения
идут по возрастанию.

~~~text
1: **
2: *
3: **
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 1 3 3 | 1: **<br>2: *<br>3: ** |
| 0 | *(пусто)* |

```bash
bash run_tests12_4.sh
```
