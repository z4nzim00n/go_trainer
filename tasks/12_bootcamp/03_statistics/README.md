## GO_12_03. Статистика

### Задание
| GO_12_03 ||
| ------ | ------- |
| **Темы:** | минимум, максимум, среднее |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи минимум, максимум и среднее арифметическое:

~~~text
Min: 1
Max: 9
Avg: 4.33
~~~

Если `N = 0`, все три значения — нули.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>1 5 7 | Min: 1<br>Max: 7<br>Avg: 4.33 |
| 0 | Min: 0<br>Max: 0<br>Avg: 0.00 |
