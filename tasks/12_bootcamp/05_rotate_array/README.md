## GO_12_05. Циклический сдвиг

### Задание
| GO_12_05 ||
| ------ | ------- |
| **Темы:** | срезы, `append`, `%` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, сдвиг K, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сдвинь массив вправо на `K` позиций (циклически) и выведи через пробел.
`K` может быть больше `N`.

~~~text
4 5 1 2 3
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5 2<br>1 2 3 4 5 | 4 5 1 2 3 |
| 5 7<br>1 2 3 4 5 | 4 5 1 2 3 |
| 1 3<br>7 | 7 |

### Как проверить

```bash
bash run_tests12_5.sh
```
