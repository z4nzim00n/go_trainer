## GO_12_01. Проверка на простое число

### Задание
| GO_12_01 ||
| ------ | ------- |
| **Темы:** | циклы, `math.Sqrt`, ранний выход |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число |
