## GO_12_06. Сумма матрицы

### Задание
| GO_12_06 ||
| ------ | ------- |
| **Темы:** | вложенные срезы, двойной цикл |
| **Файл решения:** | main.go |
| **Входные данные:** | Число строк R, число столбцов C, затем R×C чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай матрицу размера `R × C` и выведи сумму всех элементов:

~~~text
Sum: 21
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2 3<br>1 2 3<br>4 5 6 | Sum: 21 |
| 1 1<br>7 | Sum: 7 |
| 0 0 | Sum: 0 |

bash run_tests12_6.sh
