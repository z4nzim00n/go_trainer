## GO_12_02. Кофейный автомат

### Задание
| GO_12_02 ||
| ------ | ------- |
| **Темы:** | накопление, условия, форматирование |
| **Файл решения:** | main.go |
| **Входные данные:** | Число монет N, затем N номиналов |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Кофе стоит 50. Считай `N` монет и их номиналы.
Если сумма не меньше 50, выведи `Coffee: <сдача>`, иначе `Need: <недостаёт>`.

~~~text
Coffee: 10
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>20 20 20 | Coffee: 10 |
| 1<br>20 | Need: 30 |
| 2<br>50 10 | Coffee: 10 |

### Как проверить

```bash
bash run_tests12_2.sh
```
