## GO_04_01. Максимум последовательности

### Задание
| GO_04_01 ||
| ------ | ------- |
| **Темы:** | `for`, чтение последовательности |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N`, затем `N` целых чисел. Выведи максимальное из них.

Гарантируется, что `N >= 1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>3 9 -2 9 0 | 9 |
| 1<br>-42 | -42 |
| 4<br>-5 -1 -9 -3 | -1 |
