## GO_04_06. Число без пары

### Задание
| GO_04_06 ||
| ------ | ------- |
| **Темы:** | XOR `^`, `for` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


В последовательности каждое число встречается дважды, кроме одного. Найди и
выведи число без пары.

Реши за один проход и без дополнительных коллекций — через XOR.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 3 2 1 | 3 |
| 3<br>4 4 -7 | -7 |
| 1<br>42 | 42 |

```bash
bash run_tests4_6.sh
```
