## GO_04_04. Разворот числа

### Задание
| GO_04_04 ||
| ------ | ------- |
| **Темы:** | `%`, `/`, накопление результата |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи его цифры в обратном порядке, как число.

Примеры: `12340` → `4321`, `100` → `1`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 12340 | 4321 |
| 0 | 0 |
| 100 | 1 |

bash run_tests4_4.sh
