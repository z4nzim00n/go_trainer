## GO_04_03. Максимальная цифра

### Задание
| GO_04_03 ||
| ------ | ------- |
| **Темы:** | `%`, `/`, `for` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи его максимальную цифру.

Для отрицательного числа знак игнорируется: `-907` → `9`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2739 | 9 |
| 0 | 0 |
| 907 | 9 |

### Как проверить

```bash
bash run_tests4_3.sh
```
