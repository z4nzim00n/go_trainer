## GO_04_02. Сумма цифр

### Задание
| GO_04_02 ||
| ------ | ------- |
| **Темы:** | `%`, `/`, `for` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай целое число и выведи сумму его цифр.

Для отрицательного числа цифры берутся по модулю: `-123` → `1 + 2 + 3 = 6`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 12345 | 15 |
| 0 | 0 |
| -123 | 6 |

### Как проверить

```bash
bash run_tests4_2.sh
```
