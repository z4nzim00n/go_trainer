## GO_04_05. FizzBuzz

### Задание
| GO_04_05 ||
| ------ | ------- |
| **Темы:** | `for`, `%`, `if`/`else if` |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно целое число N |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Выведи числа от 1 до `N` по одному в строке, но:

- вместо чисел, кратных 3, — `Fizz`;
- вместо чисел, кратных 5, — `Buzz`;
- вместо чисел, кратных и 3, и 5, — `FizzBuzz`.

Пример для `N = 5`:

~~~text
1
2
Fizz
4
Buzz
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5 | 1<br>2<br>Fizz<br>4<br>Buzz |
| 3 | 1<br>2<br>Fizz |
| 0 | *(пусто)* |

### Как проверить

```bash
bash run_tests4_5.sh
```
