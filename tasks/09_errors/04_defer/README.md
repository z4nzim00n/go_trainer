## GO_09_04. Порядок defer

### Задание
| GO_09_04 ||
| ------ | ------- |
| **Темы:** | `defer`, порядок выполнения |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно слово |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Напиши функцию `process(word string)`, которая печатает:

~~~text
open <word>
work
close
~~~

Строка `close` должна выводиться через `defer`, чтобы она выполнилась
последней.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| hive | open hive<br>work<br>close |
| go | open go<br>work<br>close |

bash run_tests9_4.sh
