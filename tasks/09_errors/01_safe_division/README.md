## GO_09_01. Безопасное деление

### Задание
| GO_09_01 ||
| ------ | ------- |
| **Темы:** | `error`, `errors.New`, множественный возврат |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа A и B |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Напиши функцию `Divide(a, b int) (int, error)`. Если `b == 0`, верни ошибку
`division by zero`. Иначе верни результат и `nil`.
Выведи `Result: ...` или `Error: division by zero`.

~~~text
Result: 5
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 10 2 | Result: 5 |
| 5 0 | Error: division by zero |

```bash
bash run_tests9_1.sh
```
