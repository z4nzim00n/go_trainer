## GO_09_02. Разбор числа

### Задание
| GO_09_02 ||
| ------ | ------- |
| **Темы:** | `strconv.Atoi`, проверка ошибки |
| **Файл решения:** | main.go |
| **Входные данные:** | Одно слово |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай строку и попробуй превратить её в целое число через `strconv.Atoi`.
Если получилось — выведи `Number: ...`, иначе — `Invalid number`.

~~~text
Number: 42
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 42 | Number: 42 |
| abc | Invalid number |

bash run_tests9_2.sh
