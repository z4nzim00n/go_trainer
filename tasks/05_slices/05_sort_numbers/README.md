## GO_05_05. Сортировка чисел

### Задание
| GO_05_05 ||
| ------ | ------- |
| **Темы:** | `sort.Ints`, срезы |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N` чисел, отсортируй их по возрастанию и выведи через пробел.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>5 1 4 2 3 | 1 2 3 4 5 |
| 4<br>-1 3 -5 0 | -5 -1 0 3 |
| 3<br>7 7 1 | 1 7 7 |

bash run_tests5_5.sh
