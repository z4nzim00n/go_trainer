## GO_05_02. Минимум и максимум

### Задание
| GO_05_02 ||
| ------ | ------- |
| **Темы:** | срезы, `for`, `range` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N`, затем `N` чисел и выведи минимум и максимум:

~~~text
Min: -2
Max: 9
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>3 9 -2 9 0 | Min: -2<br>Max: 9 |
| 1<br>-42 | Min: -42<br>Max: -42 |
| 4<br>-5 -1 -9 -3 | Min: -9<br>Max: -1 |

bash run_tests5_2.sh
