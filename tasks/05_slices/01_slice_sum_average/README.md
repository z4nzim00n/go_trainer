## GO_05_01. Сумма и среднее

### Задание
| GO_05_01 ||
| ------ | ------- |
| **Темы:** | срезы, `append`, `len`, `float64` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Считай `N`, затем `N` чисел. Выведи сумму и среднее:

~~~text
Sum: 6
Avg: 2.00
~~~

Если `N = 0`, сумма и среднее равны нулю.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>1 2 3 | Sum: 6<br>Avg: 2.00 |
| 1<br>5 | Sum: 5<br>Avg: 5.00 |
| 0 | Sum: 0<br>Avg: 0.00 |

### Как проверить

```bash
bash run_tests5_1.sh
```
