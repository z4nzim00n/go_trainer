## GO_05_04. Удаление дубликатов

### Задание
| GO_05_04 ||
| ------ | ------- |
| **Темы:** | срезы, `map`, порядок элементов |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Удали повторяющиеся числа, сохранив порядок первого появления. Выведи результат
через пробел.

Пример: `1 2 1 3 2 4` → `1 2 3 4`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 6<br>1 2 1 3 2 4 | 1 2 3 4 |
| 4<br>3 1 3 2 | 3 1 2 |
| 5<br>5 5 5 5 5 | 5 |

### Как проверить

```bash
bash run_tests5_4.sh
```
