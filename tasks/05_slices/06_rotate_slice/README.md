## GO_05_06. Циклический сдвиг

### Задание
| GO_05_06 ||
| ------ | ------- |
| **Темы:** | срезы, `%`, индексы |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, сдвиг K, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сдвинь срез **влево** на `K` позиций по кругу и выведи результат через пробел.

Пример: `1 2 3 4 5` при `K = 2` → `3 4 5 1 2`.

Если `K` больше `N`, используй остаток `K % N`.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5 2<br>1 2 3 4 5 | 3 4 5 1 2 |
| 4 0<br>1 2 3 4 | 1 2 3 4 |
| 3 4<br>7 8 9 | 8 9 7 |

bash run_tests5_6.sh
