## GO_05_03. Разворот среза

### Задание
| GO_05_03 ||
| ------ | ------- |
| **Темы:** | срезы, индексы, `strings.Join` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N`, затем `N` чисел и выведи их в обратном порядке через пробел.

Реши двумя способами: можно развернуть срез на месте, а можно просто печатать
элементы с конца.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 5<br>1 2 3 4 5 | 5 4 3 2 1 |
| 4<br>10 20 30 40 | 40 30 20 10 |
| 1<br>7 | 7 |

```bash
bash run_tests5_3.sh
```
