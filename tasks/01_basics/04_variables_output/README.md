## GO_01_04. Переменные и вывод

### Задание
| GO_01_04 ||
| ------ | ------- |
| **Темы:** | `var`, `:=`, `int`, `string`, `fmt.Printf` |
| **Файл решения:** | main.go |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Объяви две переменные:

- `name` типа `string` со значением `Gopher`;
- `age` типа `int` со значением `15`.

Выведи их в формате:

~~~text
Name: Gopher
Age: 15
~~~

Используй `fmt.Printf` с глаголами `%s` и `%d` или конкатенацию строк.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| *(нет ввода)* | `Name: Gopher`<br>`Age: 15` |
