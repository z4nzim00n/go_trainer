## GO_01_05. Обмен значений

### Задание
| GO_01_05 ||
| ------ | ------- |
| **Темы:** | `fmt.Scan`, множественное присваивание |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа через пробел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай два целых числа `a` и `b` и выведи их в обратном порядке.

В Go можно поменять значения местами одной строкой:

~~~go
a, b = b, a
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 5 | 5 3 |
| -1 7 | 7 -1 |
| 42 42 | 42 42 |

### Как проверить

```bash
bash run_tests1_5.sh
```
