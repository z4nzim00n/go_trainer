## GO_01_03. Исправь отсутствующий импорт

### Задание
| GO_01_03 ||
| ------ | ------- |
| **Темы:** | `import`, `fmt`, ошибки компиляции |
| **Файл решения:** | main.go |
| **Входные данные:** | Не требуются |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Программа использует `fmt.Println`, но забыла импортировать пакет `fmt`,
поэтому не компилируется.

Добавь нужный импорт, чтобы программа вывела:

~~~text
Imported!
~~~

Это задание «найди и исправь ошибку»: стартовый файл намеренно **не
компилируется**.

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| *(нет ввода)* | `Imported!` |

### Как проверить

```bash
bash run_tests1_3.sh
```
