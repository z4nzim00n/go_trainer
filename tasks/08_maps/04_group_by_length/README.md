## GO_08_04. Группировка по длине

### Задание
| GO_08_04 ||
| ------ | ------- |
| **Темы:** | `map[int][]string`, вложенные срезы, сортировка |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка со словами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Сгруппируй слова по длине. Выведи группы по возрастанию длины, слова внутри
группы — по алфавиту:

~~~text
1: a
3: bee cat dog
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| a cat dog bee | 1: a<br>3: bee cat dog |
| go | 2: go |

### Как проверить

```bash
bash run_tests8_4.sh
```
