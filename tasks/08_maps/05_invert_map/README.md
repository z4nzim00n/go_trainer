## GO_08_05. Инверсия map

### Задание
| GO_08_05 ||
| ------ | ------- |
| **Темы:** | `map`, `strconv.Atoi`, сортировка числовых ключей |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N пар «слово число» |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N` пар «слово число» в `map[string]int`, затем построй обратную
map `map[int]string`. Выведи пары по возрастанию числа:

~~~text
1: a
2: b
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>a 1<br>b 2<br>c 3 | 1: a<br>2: b<br>3: c |
| 2<br>z 10<br>y 5 | 5: y<br>10: z |

### Как проверить

```bash
bash run_tests8_5.sh
```
