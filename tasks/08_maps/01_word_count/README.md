## GO_08_01. Подсчёт слов через map

### Задание
| GO_08_01 ||
| ------ | ------- |
| **Темы:** | `map`, `strings.Fields`, сортировка ключей |
| **Файл решения:** | main.go |
| **Входные данные:** | Одна строка со словами |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Посчитай, сколько раз встречается каждое слово. Выведи слова в алфавитном
порядке в формате `слово: количество`:

~~~text
apple: 2
banana: 1
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| apple banana apple | apple: 2<br>banana: 1 |
| a | a: 1 |

```bash
bash run_tests8_1.sh
```
