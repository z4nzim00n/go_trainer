## GO_08_03. Уникальные элементы

### Задание
| GO_08_03 ||
| ------ | ------- |
| **Темы:** | `map[int]bool`, множество, `sort.Ints` |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N целых чисел |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Найди уникальные числа, выведи их количество и сами числа по возрастанию:

~~~text
Unique: 4
1 2 3 4
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 6<br>3 1 3 2 1 4 | Unique: 4<br>1 2 3 4 |
| 2<br>5 5 | Unique: 1<br>5 |
| 1<br>-1 | Unique: 1<br>-1 |
