## GO_08_02. Идиома comma-ok

### Задание
| GO_08_02 ||
| ------ | ------- |
| **Темы:** | `map`, `comma ok`, отличие нулевого значения |
| **Файл решения:** | main.go |
| **Входные данные:** | Число N, затем N пар «ключ значение», затем ключ для поиска |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Считай `N`, затем `N` пар «слово число». Сохрани их в `map[string]int`.
Затем считай слово для поиска. Если оно есть в map — выведи число, иначе
выведи `NOT FOUND`.

~~~text
7
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3<br>cat 5<br>dog 7<br>fish 2<br>dog | 7 |
| 1<br>a 0<br>a | 0 |
| 1<br>a 1<br>b | NOT FOUND |
