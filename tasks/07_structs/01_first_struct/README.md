## GO_07_01. Первая структура

### Задание
| GO_07_01 ||
| ------ | ------- |
| **Темы:** | структуры, поля, `fmt.Scan` |
| **Файл решения:** | main.go |
| **Входные данные:** | Два целых числа X и Y |
| **Выходные данные** | Стандартный поток вывода (stdout) |

Опиши структуру `Point` с полями `X` и `Y` типа `int`.
Считай два числа в поля структуры и выведи их:

~~~text
X: 3
Y: 4
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 3 4 | X: 3<br>Y: 4 |
| -1 0 | X: -1<br>Y: 0 |
