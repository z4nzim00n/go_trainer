## GO_07_05. Встраивание структур

### Задание
| GO_07_05 ||
| ------ | ------- |
| **Темы:** | встраивание, продвижение полей |
| **Файл решения:** | main.go |
| **Входные данные:** | Имя сотрудника и название компании |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши структуру `Person` с полем `Name`.
Опиши структуру `Employee`, которая **встраивает** `Person` и добавляет поле
`Company`. Считай два слова и выведи:

~~~text
Name: Bob, Company: Acme
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| Bob Acme | Name: Bob, Company: Acme |
| Ann Globex | Name: Ann, Company: Globex |

### Как проверить

```bash
bash run_tests7_5.sh
```
