## GO_07_04. Интерфейс Stringer

### Задание
| GO_07_04 ||
| ------ | ------- |
| **Темы:** | `String()`, `fmt.Stringer`, форматирование |
| **Файл решения:** | main.go |
| **Входные данные:** | Температура одним числом |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши тип `Temperature float64` и реализуй метод `String() string`,
который печатает температуру с двумя знаками и знаком градуса:

~~~text
Temp: 21.50°C
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 21.5 | Temp: 21.50°C |
| -5 | Temp: -5.00°C |

bash run_tests7_4.sh
