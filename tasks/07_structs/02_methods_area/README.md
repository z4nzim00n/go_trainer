## GO_07_02. Метод Area

### Задание
| GO_07_02 ||
| ------ | ------- |
| **Темы:** | методы, получатель, `float64` |
| **Файл решения:** | main.go |
| **Входные данные:** | Ширина и высота прямоугольника |
| **Выходные данные** | Стандартный поток вывода (stdout) |


Опиши структуру `Rectangle` с полями `Width` и `Height`.
Добавь метод `Area() float64`, возвращающий площадь.
Считай два числа и выведи площадь с двумя знаками:

~~~text
Area: 10.00
~~~

### Примеры

| Входные данные | Результат работы |
| ------ | ------ |
| 2.5 4 | Area: 10.00 |
| 1 1 | Area: 1.00 |
